# LoopProof Recipes

Readable web versions of the LoopProof looping tutorials for the
Behringer Kick (0700-AAM): a song is decomposed into a tutorial, then
the tutorial is proven correct by following it in a screen recording
of the simulator — the song is the proof.

**Read them here: https://rasrobo.github.io/loopproof-recipes/**

- [Canon in D](https://rasrobo.github.io/loopproof-recipes/canon-in-d.html)
- [Canon in D, Part 2 — The Melody](https://rasrobo.github.io/loopproof-recipes/canon-in-d-part-2.html)
- [House of the Rising Sun](https://rasrobo.github.io/loopproof-recipes/house-of-the-rising-sun.html)
- [Für Elise](https://rasrobo.github.io/loopproof-recipes/fur-elise.html)
- [The Rubric](https://rasrobo.github.io/loopproof-recipes/rubric.html) — how the layers are kept honest

Every recipe comes from a verified score, is machine-checked note for
note, and can be recreated in the free
[0700-AAM simulator](https://rasrobo.github.io/0700-aam-sim/) — no
hardware needed. This site is generated from the tutorials in the
LoopProof project repo; everything is open source.
